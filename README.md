# Optimisation des prix avec Python

> Pricing Analytics / Python

## Vue d'ensemble

Projet d'analyse et d'optimisation des prix à partir de données de marché et de concurrence. Le dépôt contient un notebook d'optimisation, des données CSV et un script d'analyse quantitative.

## Objectifs du projet

- Analyser l’effet du prix sur la performance commerciale.
- Étudier la concurrence et les tendances de marché.
- Identifier des pistes d’optimisation tarifaire.
- Produire des visualisations pour soutenir une décision pricing.

## Démarche

- Chargement des données de prix et concurrence.
- Analyse exploratoire des distributions et relations.
- Comparaison de scénarios ou niveaux de prix.
- Synthèse des leviers d’optimisation.

## Stack technique
